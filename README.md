# CGV 좌석 감시 · 자동잡기 (cgv-macro)

CGV 취소표/오픈을 감지해서, 내가 녹화해 둔 예매 흐름 그대로 좌석을 자동으로 잡고 결제 페이지까지 진입하는 개인용 도구.

- 감지: CGV 공개 예매 API 폴링(무인증, 가벼움)로 대상 회차의 잔여석을 확인.
- 자동잡기: 최초 1회 “녹화”한 클릭 순서를 실제 로그인 크롬으로 재생. 날짜/회차/인원/좌석만 대상에 맞춰 자동 처리.
- 좌석: 관(2D/IMAX/4DX)마다 배치가 달라도 그 관의 “빈 좌석”을 실시간으로 잡음. 원하는 좌석 지정/대기 가능.
- 결제: “결제 전 확인” 모달까지 눌러 결제수단 페이지에서 멈춤(좌석 선점). 실제 카드 결제만 사용자가 직접.

> 개인 용도. 과도한 폴링은 자제(기본 10초). CGV UI 변경 시 셀렉터 수정이 필요할 수 있음.

## 요구사항
- Windows + Google Chrome 설치
- Python 3.10+ (exe로 쓰면 불필요)

## 사용법 (소스로 실행)
1. `run_app.bat` 더블클릭 → 처음 1회 자동 설치 후 GUI 실행.
2. GUI에서:
   - `녹화 시작하기` → 크롬에서 CGV 로그인 → `① 로그인함·녹화시작` → 예매를 좌석 선택완료·결제하기까지 클릭 → `② 녹화끝(저장)`. (최초 1회)
   - 대상 설정: 영화/극장/날짜/회차시간(비우면 전체)/인원(일반·청소년·우대)/원하는 좌석/좌석위치/폴링주기.
   - `감시 시작` → 로그인 확인 → 감시. 취소표/오픈이 감지되면 좌석을 잡고 결제 페이지까지 진입.

## exe로 빌드 (배포)
- `build_exe.bat` 더블클릭 → `dist\CGV-Seat-Watcher.exe` 생성(설치된 크롬 사용, 용량 작음).

## 구성
- `cgv_macro/cgv_api.py` — 무인증 예매 API(회차/잔여석/영화·극장 코드).
- `cgv_macro/recorder.py`, `record.py` — 클릭 녹화 → `recipe.json`.
- `cgv_macro/replayer.py` — 녹화 재생(좌석 자동잡기 + 결제 진입).
- `cgv_macro/watcher.py` — 감지 → 자동잡기 루프.
- `app.py` — GUI.

## 저장 위치
- 설정/녹화/로그: `%APPDATA%\CGV-Ticket-Watcher\` (config, recipe.json, chrome-profile, logs).

## CGV 구조가 바뀌면
- 회차/좌석/결제 셀렉터는 `cgv_macro/replayer.py`, 감지는 `cgv_macro/cgv_api.py`에 모여 있음. 필요 시 그 부분만 수정.
